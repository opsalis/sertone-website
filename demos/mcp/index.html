Protocol Demo

Model Context Protocol on Sertone

Connect your control center as an MCP server and every API in your catalog becomes a tool an AI agent can call. Claude routes the call, the wrapper settles USDC, and the result flows straight back into the conversation.

Live Demo — This demo runs on a testnet using test USDC. When you install your own Sertone, it connects to the production blockchain with real USDC.

How It Works

Your control center runs an MCP server (port 3003) that exposes each catalog API as a tool. An AI agent calls a tool by name; the wrapper routes the call, settles the per-call fee in USDC, and returns the result to the agent's conversation. The agent never handles keys, billing, or protocol details.

Why MCP on Sertone?

Model Context Protocol (MCP) is an open standard that lets AI assistants call external tools and data sources. When your control center is connected as an MCP server, Claude and other agents can search your catalog, call APIs, and use the results directly in conversation — no copy-pasting, no manual steps.

Each API in your catalog becomes a separate MCP tool — one tool per endpoint, named after the API and operation (for example Crypto_Prices_getPrice or Weather_API_getForecast). The agent picks the right tool, supplies the parameters, and the wrapper does the rest: authentication, routing, and USDC settlement.

Real-world example: you ask Claude “What’s the current price of Bitcoin and the 5-day forecast for Tokyo?” Claude calls two Sertone tools, your wallet is debited per call, and both answers land in the same reply. Any API you can buy on the marketplace becomes something your agent can use.

Connect Your Agent

# Add your control center as an MCP server in claude_desktop_config.json
{
  "mcpServers": {
    "sertone": {
      "url": "https://localhost:3003/mcp",
      "headers": { "Authorization": "Bearer YOUR_MCP_TOKEN" }
    }
  }
}
# Restart Claude Desktop — your catalog APIs now appear as tools.
# Register the MCP server with Claude Code
$ claude mcp add --transport http sertone \
    https://localhost:3003/mcp \
    --header "Authorization: Bearer YOUR_MCP_TOKEN"

# Then just ask — each catalog API is a callable tool.
# What an agent sends under the hood (JSON-RPC over MCP)
POST https://localhost:3003/mcp
Authorization: Bearer YOUR_MCP_TOKEN

{
  "method": "tools/call",
  "params": {
    "name": "Crypto_Prices_getPrice",
    "arguments": { "symbol": "BTC" }
  }
}
# The wrapper routes the call, deducts USDC, and returns the result.

Self-Host in Minutes

1

Install the Control Center

Run the free Sertone Docker container. The MCP server starts automatically on port 3003 when your catalog loads.

$ docker run -d --name sertone \
  -p 3000-3003:3000-3003 -p 3005-3006:3005-3006 \
  -v sertone-data:/app/data \
  {{INSTALL_IMAGE}}
2

Add APIs to Your Catalog

Open the web console, browse the marketplace, and add the APIs you want. Each endpoint becomes an MCP tool automatically — no configuration.

3

Connect Your Agent

Copy your MCP token from Settings > Security and point Claude Desktop or Claude Code at https://localhost:3003/mcp using the samples above.

4

Ask in Plain Language

Your agent picks the right tool, the wrapper settles USDC per call, and results flow back into the conversation. You pay only for what the agent uses.
